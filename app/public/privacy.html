The short version

There are no accounts, no logins, no cookies, no advertising, and no analytics or tracking scripts. The site does not build a profile of you. Most of it is a set of pre-computed statistics files that your browser downloads and reads locally.

What the site stores in your browser

Nothing. Hexcall does not set cookies and does not write to local storage or session storage. Your augment selections exist only in the page's memory and are gone when you close the tab.

Aggregate statistics

The comp, augment, champion, item and trait statistics are computed in advance from public match data supplied by the Riot Games API. Published statistics are aggregates — counts and average placements across thousands of matches. They contain no player names, no Riot IDs, and no per-player records.

The match data behind those statistics

To produce the aggregates, the crawler stores raw match records returned by the Riot Games API. Those records include PUUIDs — pseudonymous per-player identifiers issued by Riot. They are used only to filter matches by ranked tier (so that, for example, a "Challenger" statistic counts only Challenger players' boards) and are never published, displayed, or shared. This store lives on the machine running the crawler.

"Review My Games"

This is the only feature that sends anything anywhere, and it is only available when the site is run against its own stats server:

  • You type a Riot ID. It is sent to the server, which passes it to the Riot Games API to look up that account's recent ranked match history.
  • The result is analysed and returned to you, and held in the server's memory for about ten minutes so a repeated lookup doesn't cost another set of Riot API calls.
  • It is not written to disk, not associated with you, and not shared with anyone. Restarting the server clears it.

Only submit your own Riot ID. The feature exists to show a player their own history.

Server logs

If you use a deployment that runs the stats server, that server — like essentially any web server — may record request metadata including IP addresses. IP addresses are also used in memory to rate-limit the review endpoint so that one visitor cannot exhaust the shared Riot API budget. On a purely static deployment, logging is whatever your static host does.

Third parties

  • Riot Games API — the source of all match data, and where a review lookup is sent.
  • Data Dragon and Community Dragon — champion, item, trait and augment artwork and reference data. Your browser loads images directly from these, so those hosts will see the requests.
  • Google Fonts — the site loads its typefaces from Google's font CDN.
  • Your hosting provider — whoever serves the site.

No data is sold, and nothing is shared with advertisers.
